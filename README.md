# EmberAI

EmberAI is an original, privacy-conscious storytelling and character platform for the web and Android. This monorepo contains shared domain, AI, and memory contracts; a web shell; an API foundation; and a native Android foundation.

## Development

```bash
npm install
npm run check
npm run build
```

See [docs/architecture.md](docs/architecture.md) for system boundaries and [docs/safety-and-privacy.md](docs/safety-and-privacy.md) for product safeguards.
